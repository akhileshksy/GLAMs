About this directory

GLAM is the shorthand used by cultural heritage professionals for galleries, libraries, archives and museums: institutions that collect, preserve and share knowledge. India has thousands of them, from national bodies to small community collections, but there is no single open list.

Sangrah (संग्रह, “a collection”) starts with well-known institutions and is built to grow through contributions. Everything lives in one JSON file in the repository, so it is easy to reuse, check and improve.

  • Open data. data/glams.json, reusable under CC0.
  • No server. Plain HTML, CSS and JavaScript on GitHub Pages.
  • Sources first. Each entry links to the institution's own site where one exists.
  • Check before you travel. Hours, tickets and access rules change; confirm on the official site.
